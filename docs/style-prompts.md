# N2K Style Prompt Export

This export summarizes the active v3 style system and provides one copy-ready prompt for each included edition. Source review covered:

- `web/src/core/themes.ts`: canonical edition registry, labels, taglines, layouts, glyph variants, equation variants, ornaments, swatches, heatmap palettes.
- `web/src/styles.css`: CSS-variable bundles, theme treatments, typography, surfaces, focus and print behavior.
- `web/src/ui/chrome/layouts/*`: page composition variants.
- `web/src/ui/primitives/DiceGlyph.tsx` and `Equation.tsx`: dice and equation rendering variants.
- `web/src/ui/chrome/nav.ts`: navigation labels and edition colophons.

## Shared Style System Prompt

Build an N2K Almanac interface: a dense, tactile, editorial math-game reference app for dice triples, equations, competitions, saved libraries, and play mode. Preserve the app's core navigation surfaces: Lookup ("Pick dice, find an equation"), Competition ("Phases, boards, balanced rolls"), Library ("Saved comps, ready to play"), and Play ("Quick Race / Match / Hot-seat"). Use theme-driven CSS variables for all colors and fonts: `paper`, `ink`, `accent`, and `support`, each with tonal ramps. Keep the UI functional and information-rich rather than marketing-like. Page chrome, typography, dice glyphs, equation display, dividers, inputs, focus rings, and heatmap colors must all belong to the chosen edition. Use `font-display` for titles, `font-body` for prose and controls, and `font-mono` for numeric metadata. Render equations either as pretty superscript math with readable operator glyphs and an accented result, or as ASCII in terminal/receipt/spreadsheet styles. Render dice triples using the edition's glyph style. Keep navigation, edition selection, dataset stats, and footer colophon accessible in every layout. Respect responsive behavior: compact controls, stable board grids, non-overlapping text, keyboard-visible focus, and reduced-motion support.

Layouts available: `sidebar` (left masthead, vertical nav, centered page), `topbar` (horizontal masthead and nav), `manuscript` (folio rail, marginalia, illuminated page), `blueprint` (drafting grid with title block), `frame` (ornamental centered frame), `receipt` (narrow printer slip), `board` (vintage board-game frame), `platform` (subway platform), `spreadsheet` (formula bar and grid), `scrapbook` (kraft scrapbook with tilted cards), `panels` (comic panels), and `chart` (maritime chart).

Dice glyphs available: `tile`, `ascii`, `newsroom`, `pip-tile`, `illuminated`, `blueprint`, `tarot`, `boardgame`, `bullet`, `cell`, `polaroid`, `panel`, and `buoy`.
